# API REST con Patrones de Diseño (Node.js + Express)

API REST desarrollada como proyecto académico para demostrar la implementación práctica de 4 patrones de diseño software esenciales.

## 🛠️ Tecnologías Utilizadas
- **Node.js**
- **Express.js**
- **Git & GitHub**
- **REST Client Extension**

## 🧩 Patrones de Diseño Implementados

1. **Factory Method (`FabricaProducto`)**: Encargado de la creación centralizada e instanciación de productos físicos y digitales.
2. **Repository (`RepositorioMemoria`)**: Abstrae la capa de datos simulando un almacenamiento en memoria para productos y pedidos.
3. **Strategy (`ESTRATEGIAS`)**: Maneja de forma dinámica diferentes métodos de procesamiento de pago (Yape, Tarjeta, Efectivo).
4. **Observer (`ServicioNotificaciones`)**: Gestiona la suscripción y emisión de eventos del sistema (envío de correos, registros de auditoría).
